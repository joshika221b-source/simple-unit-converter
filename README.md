# 🔄 Simple Unit Converter

A simple and interactive unit conversion tool built using **HTML, CSS, and JavaScript**. It provides an easy-to-use interface for converting values between different units.

## 🚀 Live Demo

👉 **[Open Simple Unit Converter](https://joshika221b-source.github.io/simple-unit-convertor/simple%20convertor/simpleconvertor.html)**

## ✨ Features

- 📏 Length conversion — Meter ↔ Feet
- 🥛 Volume conversion — Liters ↔ Gallons
- ⚖️ Mass conversion — Kilograms ↔ Pounds
- 🔢 User input for custom values
- 🔄 Reset button
- 🌙 Dark mode
- ⚡ Instant conversion results
- 🎨 Clean and interactive interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
